# Changelog

## 1.0.0 — 2026-10-04

- Create focus sessions with a goal, preset or custom duration, and a distraction blacklist.
- Select installed applications or running processes to block by executable name.
- Block selected websites through the Windows hosts file, including common Facebook and YouTube hostnames.
- Use the compact, always-on-top focus overlay.
- Require Windows Administrator privileges for system-level blocking.

### Notes

- Website blocking applies to configured hostnames and known aliases. The Windows hosts file does not support wildcard subdomains; browser Secure DNS, cached DNS, and unlisted hostnames can affect results.
- The application targets Windows and requires Administrator privileges to modify the hosts file.
